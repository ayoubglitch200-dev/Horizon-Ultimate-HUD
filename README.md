Horizon Ultimate HUD
Minimal native-mod source package for Horizon.
Included in this draft
XYZ coordinates HUD
Right Shift menu toggle
Small in-game status panel
Not implemented
X-Ray, ESP, Fly, Speed, Fullbright and teleportation are not implemented.
Target
Minecraft 26.3
Horizon revision pinned in `mixins/horizon_ultimate_hud/horizon-mixin.toml`
Build and validation status
This repository contains source files, not a verified compiled binary. The TOML/ZIP structure can be checked locally, but a full Rust compile and in-game test have not been performed. The Horizon API symbols and injection signatures must be checked against the pinned Horizon source revision before this can be considered working.
Use the official Horizon native-mod build instructions for the exact revision. Review native code before granting native-code trust, and test in a disposable world.
